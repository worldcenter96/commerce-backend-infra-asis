## 맥락

- 운영자는 관리 접속 경로 하나를 거쳐서만 서버와 DB에 접근한다(FR-07).
- FR-04, NFR-14 검증은 관리 접속 경로에서 MySQL·Redis에 접속해 실행한다.
- 인터넷에는 서비스 진입점의 HTTPS와 관리 접속 경로만 열 수 있다(NFR-06).
- 사용자 선호는 Bastion SSH였고(Q-23), 02에서 Bastion SSH, SSM Session Manager, EC2 Instance Connect Endpoint를 비교했다.

## 결정

**Bastion Host를 거친 SSH를 채택한다.** (02 D-05 대안 A)

- 이유: (기재하지 않음)
- Bastion 인스턴스 사양: **t3.medium**. 결정자 지정(2026-11-12)

## 결과

**장점** (02 D-05 비교표)
- FR-07을 충족하고, FR-04·NFR-14 검증을 Bastion에서 바로 실행할 수 있다.
- 익숙한 방식이라 구현 난이도는 하다.
- 공인 IP를 자동 할당하면 중지했을 때 EBS만 과금된다(NFR-13). 상시 과금은 하루 약 $0.02, 월 최악은 약 $9.1이다.

**단점** (02 D-05 비교표)
- 22번 포트가 인터넷에 열린다. 출발지를 제한해야 NFR-06을 조건부로 충족한다.
- 운영자 출발지 IP를 알아야 한다(02 질문 Q-F).
- 운영 부담이 중간이다. SSH 키, 출발지 IP, 인스턴스 패치를 관리해야 한다.
