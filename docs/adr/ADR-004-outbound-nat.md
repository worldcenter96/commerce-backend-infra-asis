## 맥락

- 프라이빗 서버는 S3, 배포 도구, 일반 인터넷으로 아웃바운드 통신을 해야 한다(FR-05, Q-34).
- ~~아웃바운드는 고정 공인 IP로 나가야 하고, 중지·시작 뒤에도 IP가 바뀌면 안 된다(FR-06, Q-05).~~ (2026-11-12 변경, Q-36) 나가는 쪽은 고정 IP가 필요하지 않다. 고정 공인 IP는 들어오는 쪽(서비스 진입점)에 필요하며 [ADR-010](ADR-010-inbound-static-ip.md)에서 다룬다.
- 사용자 선호는 NAT Gateway + EIP였고(Q-23), 02에서 NAT Gateway + EIP와 NAT 인스턴스 + EIP를 비교했다.

## 결정

**NAT Gateway + EIP를 채택한다.** (02 D-04 대안 A)

- 이유: NAT GW를 사용함으로써 NAT 관리 포인트 최소화
- (2026-11-12) 고정 IP 요구가 없어졌지만 이 결정은 유지한다. 결정자 지정. NAT Gateway는 만들 때 EIP가 하나 붙으므로 그 요금은 그대로 남는다.

## 결과

**장점** (02 D-04 비교표)
- FR-05를 충족한다. ~~FR-06을 충족한다. EIP를 유지하므로 IP가 바뀌지 않는다.~~ (FR-06은 진입점 고정 IP로 바뀌어 이 결정과 관계없다)
- 들어오는 연결을 받지 않아 NFR-06을 충족한다.
- AZ 안에서 관리형으로 이중화된다. 운영 부담이 낮고 구현 난이도는 하다.

**단점** (02 D-04 비교표)
- 중지 기능이 없다. NAT Gateway 시간 요금과 EIP가 계속 과금된다(NFR-13).
- 상시 과금이 하루 약 $1.54, 월 최악이 약 $47.0이다. NAT 인스턴스(하루 약 $0.14)보다 약 11배 비싸다.
- 구축과 운영 사이 간격(Q-03)이 길수록 비용 차이가 커진다.

**예산 영향** (02 13.2절)
- 이번 결정 전체(ADR-001~ADR-010)는 02 13.2절의 "사용자 선호안"에 NLB + EIP(ADR-010)를 더한 구성이다. 중지해도 나가는 비용이 하루 ~~약 $3.16~~ 약 $3.94이고, 그중 NAT Gateway가 가장 크다.
- 리소스가 ~~**약 28일**~~ **약 23일 이상 존재하면 가동 시간과 상관없이 월 100달러(CON-01)를 넘는다.** 구축 시작부터 삭제까지 이 기간 안에 끝내야 한다.
